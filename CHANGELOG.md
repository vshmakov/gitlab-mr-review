# Change Log

All notable changes to the "gitlab-mr-review" extension will be documented in this file.

Check [Keep a Changelog](http://keepachangelog.com/) for recommendations on how to structure this file.

## [1.0.0] - 2026-09-20

- Added GitLab authentication with token storage in VS Code SecretStorage.
- Added merge request lists grouped by review status.
- Added diff viewing, draft comments, approvals, and file review tracking.
- Added persistent reviewed-file state between sessions.
- Added release preparation and GitHub publication scripts.
